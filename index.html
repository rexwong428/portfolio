About Me

Hi, I’m Rex! I’m passionate about using data to solve business problems and support better decision-making.

With over 6 years in the financial industry, I work at the point where data has to be right before it can be useful.

Today I run day to day data operations for a live rewards platform. That means keeping member, transaction and trading records accurate through cleansing, deduplication and reconciliation, building the recurring dashboards, monthly statements and P&L reporting the business runs on, and automating the fulfilment work that used to be done by hand.

Before that it was the same discipline from other angles: SQL validation and back end testing at EQ Bank, where Python automation cut manual data collection by 80%, and Power BI dashboards and UAT on financial systems at KPMG.

SQL and Python are how I check and automate, and Power BI, Tableau and Excel are how I make the result readable. I’m fluent in English, Mandarin and Cantonese, which matters when the team that owns the data and the team that needs the answer aren’t the same one.
